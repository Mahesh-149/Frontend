# 🌐 Responsive Landing Page Project

A **multi-page responsive landing page** built using **HTML, CSS, and JavaScript**.  
This project demonstrates modern frontend design with animations, dynamic features, and mobile-first responsiveness.

---

## 🚀 Features
- **Multi-page layout**: Home, About, Features, Contact  
- **Responsive design** (works on desktop, tablet, and mobile)  
- **Smooth scroll navigation**  
- **Dark mode toggle** 🌙  
- **Scroll-to-top button** ⬆️  
- **On-scroll animations** (features fade in)  
- **Dynamic Testimonials** (auto-sliding)  
- **FAQ accordion** (expand/collapse answers)  
- **Contact form with validation** ✉️  
- **Dynamic year in footer** (auto-updates every year)  

---
